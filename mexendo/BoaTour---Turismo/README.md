## 🌎 Sobre o projeto

O **BOATOUR** é uma plataforma web de turismo desenvolvida como projeto acadêmico do curso de **Informática para Internet**.

O projeto foi pensado para oferecer uma experiência simples, moderna e intuitiva para pessoas que desejam pesquisar destinos, planejar viagens e encontrar diferentes opções para sua próxima aventura.

A plataforma reúne diferentes recursos relacionados ao planejamento de viagens em uma única experiência.

---

## ✨ Funcionalidades

### 🗺️ Destinos

Explore diferentes destinos turísticos e encontre informações para escolher o lugar ideal para sua próxima viagem.

### ✈️ Voos

Pesquise opções de voos de acordo com origem, destino, datas e quantidade de passageiros.

### 🏨 Hotéis

Encontre opções de hospedagem para complementar o planejamento da viagem.

### 🎯 Atividades

Descubra atividades e experiências disponíveis nos destinos.

### 💰 Ofertas

Confira oportunidades e ofertas para encontrar opções que combinam com sua viagem.

### 🧠 Quiz de Destinos

Responda perguntas sobre seus gostos e preferências e descubra qual destino combina mais com você.

### 👤 Perfil do usuário

Área destinada ao gerenciamento das informações do usuário e acesso aos recursos da conta.

### 💳 Pagamentos

Área destinada à visualização e gerenciamento dos pagamentos realizados na plataforma.

### 💬 Chatbot

Assistente virtual para auxiliar o usuário durante a navegação pelo site.

### 🔔 Notificações

Sistema de notificações para apresentar informações importantes ao usuário.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 2. Entre na pasta

```bash
cd BOATOUR
```

### 3. Instale as dependências

Caso o projeto utilize Node.js:

```bash
npm install
```

### 4. Inicie o servidor

```bash
node server.js
```

### 5. Acesse no navegador

```text
http://localhost:3000
```

O projeto também pode ser relacionado aos **Objetivos de Desenvolvimento Sustentável (ODS)** da ONU, especialmente:

### 🏙️ ODS 11 — Cidades e Comunidades Sustentáveis

A plataforma pode incentivar escolhas mais conscientes relacionadas às experiências e atividades turísticas.
