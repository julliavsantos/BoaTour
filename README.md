## 🌎 Sobre o projeto

O **BoaTour** é uma plataforma web voltada ao universo do turismo, desenvolvida com o propósito de aproximar pessoas de novas experiências e facilitar o planejamento de viagens.

Mais do que apresentar destinos e opções de voos, o projeto busca oferecer uma experiência digital agradável, organizada e intuitiva, reunindo funcionalidades importantes em um só lugar.

Com uma interface moderna, recursos de personalização e gerenciamento de usuários, o BoaTour foi pensado para proporcionar uma navegação simples, adaptável e funcional.

**Viajar começa muito antes do embarque. Começa na descoberta.**

## ✨ Funcionalidades

O BoaTour reúne diferentes recursos para proporcionar uma experiência completa aos usuários.

- Cadastro e autenticação de usuários.
- Login e gerenciamento de sessão.

## 🚀 Como executar o projeto

Para executar o BoaTour localmente, você precisará de um ambiente de desenvolvimento PHP com suporte ao MySQL.

### 1. Pré-requisitos

- PHP
- MySQL
- Apache
- XAMPP (recomendado para ambiente local)
- Navegador atualizado

### 2. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 3. Configure o ambiente

Coloque a pasta do projeto no diretório:

```text
xampp/htdocs/
```

### 4. Configure o banco de dados

1. Inicie o Apache e o MySQL no XAMPP.
2. Acesse o phpMyAdmin.
3. Crie ou importe o banco de dados `boatour_bd`.
4. Configure a conexão com o banco no arquivo de conexão PHP do projeto.

### 5. Execute o projeto

Acesse pelo navegador:

```text
http://localhost/NOME_DA_PASTA/
```

Pronto! O BoaTour estará disponível no ambiente local.
